Security Assistant - Changelog

0.12.0

Sidebar panel
- The panel is rebuilt on Lit. Every value shown in the panel goes through Lit templates, which escape it, instead of hand-escaped HTML strings set with innerHTML.
- Rendering diffs the page instead of rebuilding it: search boxes keep focus and cursor position while tables update, and filtering or sorting large tables is faster.
- The source now lives in frontend/src (one module per view, translations as JSON files) and is bundled with esbuild; the committed homesec-panel.js is generated from it.
- The "Reload" button shown after a display error now works.
- No visual or functional change intended: every view, modal and interaction was compared against 0.11.0 in a real browser and renders the same DOM.

Testing
- Browser regression tests (Playwright) render every view, modal and main interaction against fixtures generated from the real backend, checking for page errors, injected script, leaked markup, DOM snapshots and screenshots. CI runs them on every push and checks that the committed bundle matches the sources.

0.11.0

Privacy
- The active network scanner and ipwho.is IP geolocation are now opt-in, chosen on a new privacy step during setup (and in the integration options / Settings page). Existing installs keep their current behaviour through a config-entry migration.
- The scanner never probes Home Assistant's own addresses.
- DNS queries from outside the allowed networks are counted instead of logged.

Home Assistant integration
- Repair issues for a DNS proxy or Suricata listener that cannot bind, listeners open to any sender, and empty blocklists. A Suricata bind failure no longer stops the whole integration from loading.
- Diagnostics download with secrets redacted.
- Sensors: translated names, long-term statistics (state classes), diagnostic categories, service device type; the NVD keywords attribute is now a single list.
- New settings fields translated in the panel (FR/DE/ES/IT).

Performance
- DNS proxy reuses one UDP socket per upstream with randomised transaction IDs, question matching and a cap on queries in flight.
- NetFlow datagrams are parsed in batches outside the receive callback.
- NVD pages and the CISA KEV catalog are parsed in the executor; reverse DNS uses aiodns.
- The panel stops polling while the browser tab is hidden.

Maintenance
- README screenshots moved to docs/images (2 MB less in every install).
- ruff and mypy run in CI; removed six shadowed duplicate entries in the DNS category list (no behaviour change).

0.10.0

Security
- Fixed stored XSS: Suricata alert fields (notably signature_id) and external hostnames/ISP names could inject script into the panel. All panel output is now escaped and Suricata fields are type-checked and length-limited server-side; stored alerts from older versions are re-validated on load.
- Suricata listener: optional shared auth token (suricata_pusher.py --token / HSA_SURICATA_TOKEN) and allowed-source list, connection cap, receive-time timestamps, bounded log.
- NetFlow listener: optional exporter allowlist; template cache capped per exporter.
- Every /api/homesec endpoint now checks permissions: changes always require an admin; reads require an admin unless "Sidebar panel requires admin" is off.
- Regex dismiss runs off the event loop.
- Settings are validated (types, ranges, IPs/CIDRs, HTTPS-only URLs) before they are saved; invalid stored values no longer stop the integration from loading.
- API keys are no longer written to /config/homesec.yaml.
- Threat-intel blocklists are swapped in atomically; a failed download keeps the previous entries instead of disabling blocking.
- GitHub Actions pinned to commit SHAs; Dependabot added.

Home Assistant integration
- State moved from /config/homesec_*.yaml to Home Assistant storage (.storage/homesec.*) with atomic, batched writes. Old files are migrated once and deleted.
- homesec_malicious_ip and homesec_critical_vulnerability events now fire once per new occurrence instead of every 30 seconds.
- Uses entry.runtime_data, single_config_entry, services registered once, entry-scoped background tasks; stored data is deleted when the integration is removed.
- Settings changes apply in place when possible, otherwise trigger one reload (previously both ran at once).
- Options flow no longer wipes settings made in the panel; setup/options validate host and networks.
- Removed unused requirements (python-dateutil, cachetools); minimum Home Assistant 2025.1.0.

Performance
- Dashboard API returns the latest 2,000 DNS/Suricata log entries (paginated) and no longer duplicates the whole state; chart state is written only when it changes.
- Coordinator data no longer carries the full logs; baseline and timeseries no longer rescan the whole DNS log every refresh.
- Bounded memory: DNS/Suricata logs (10,000), devices (2,048), peers per device, external IPs (10,000), enrichment and reverse-DNS caches (5,000).

Fixes
- blacklist_refresh no longer stops reverse DNS and periodic blocklist refreshes.
- VirusTotal is used when it is the only reputation key configured.
- A failed NVD fetch no longer empties CVE coverage for 12 hours.
- DNS proxy answers over TCP and IPv6 (truncated UDP answers can now be retried); bare IPv6 upstreams parse correctly.
- Baseline training no longer counts the same DNS queries on every refresh.
- Idle devices expire by local receive time, not the exporter's clock.

Vulnerability findings
- Findings, Vulnerability Browser and CVE details now warn that banner-based CVE matches can be false positives when a distribution backports fixes (FR/DE/ES/IT translated); README FAQ explains how to verify.
- Grouped finding rows show the CVE ID.

Branding
- Brand images ship in custom_components/homesec/brand (Home Assistant 2026.3+). The HACS 2.0.x store cannot show local brand icons; Home Assistant 2026.11 (Marketplace) does.

Tests
- Added pytest suite (config flow, setup/unload, migration, API access, end-to-end traffic, parser fuzzing with Hypothesis) and Node panel escaping tests; new Tests workflow.

- Fixed DNS search focus issue - DNS query log filter now responds only to Enter key presses instead of firing on every keystroke, eliminating focus-stealing re-renders that interrupted typing.
- Fixed JavaScript variable hoisting bugs - corrected multiple variable scope issues in the frontend.
- Fixed DNS category map - removed duplicate function definitions in dns_categories.py that were silently overwriting the comprehensive domain mapping with an incomplete version, causing excessive other categorization.
- Logo integration - replaced inline SVG with external image reference for cleaner HTML structure.
